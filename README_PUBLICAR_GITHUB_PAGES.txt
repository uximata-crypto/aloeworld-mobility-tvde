PUBLICAÇÃO SIMPLES NO GITHUB PAGES

Este pacote foi preparado para resolver o problema do upload da pasta dist no GitHub.

1. Extraia este ZIP.
2. Faça upload APENAS do ficheiro index.html para o repositório GitHub.
3. No GitHub, vá a Settings > Pages.
4. Escolha Deploy from a branch.
5. Branch: main.
6. Folder: /root.
7. Save.

Como esta versão tem tudo dentro de um único ficheiro index.html, não precisa de enviar a pasta dist nem a pasta assets.
